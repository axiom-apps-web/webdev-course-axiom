# Fundamentos de Desarrollo Web

## Resumen del Curso
Este curso de 1 hora introduce a estudiantes de secundaria a la creación de sitios web sencillos con HTML y CSS. **¡No
requiere descargas!** Solo abre tu navegador web.

**Duración total**: ~60 minutos

**Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación

**Prerrequisitos**: Ninguno

**Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge)

**📂 Repositorio de código fuente**: [https://github.com/axiom-apps-web/webdev-course-axiom](https://github.com/axiom-apps-web/webdev-course-axiom)
## Secuencia de la lección
### Lección 1: Introducción al desarrollo web (8:11 minutos)


* **Descripción**: Aprende de qué están hechos los sitios web y por qué HTML y CSS son los componentes básicos.
* **Enlace**: [Ver la lección](https://youtu.be/Hk5tmD_LWaA)
* **Consejos clave**: Sitios web = Contenido (HTML) + Estilo (CSS).
* **Empieza a programar**: [Open CodePen](https://codepen.io/pen/?template=your-starter)



### Lección 2: Estructura básica de HTML (3:24 minutos)
- **Descripción**: Explicación del esqueleto básico de un documento HTML y de los elementos que lo componen para comprender cómo se organiza una página web.
- **Enlace**: [Ver la lección](https://youtu.be/pZCNaSrKooY)
- **Conceptos clave**:
  - **Etiqueta**: Una palabra escrita entre `< >`, por ejemplo `<p>`.
  - **Elemento**: La etiqueta de apertura, el contenido y la etiqueta de cierre.
  - **Atributo**: Información extra dentro de la etiqueta, como `src` o `href`.
